C3 广告拦截器 浏览器一键烧录

给 ESP32-C3 烧录一个网络级广告拦截器

$2 的芯片，14 万+ 拦截域名，无需 PSRAM。在这里直接烧录，无需安装任何工具链。

把 ESP32-C3 插到这台电脑上，然后：

你的浏览器无法烧录——请在桌面端使用 Chrome 或 Edge。 需要授权访问串口。
Chrome / Edge · 桌面端 约 30 秒 含拦截列表

烧录过程

  1. 点击 连接并安装，选择 ESP32-C3 的串口。
  2. 固件和 14 万域拦截列表会一起刷入（约 30 秒）。
  3. 重启后会生成一个名为 C3-AdBlock-XXXX 的 WiFi——用手机连上它，选择你家的 WiFi 并输入密码。
  4. 把它设为路由器的副 DNS（或按设备设置），广告即被全网拦截。控制台地址 c3adblock.local。

这个固件里没有预置任何 WiFi 凭据——你在设备上私有设置。
